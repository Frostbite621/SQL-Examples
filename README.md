# SQL-Examples
Collection of SQL statements to display knowledge of the SQL language. Includes queries, subqueries, and creation.
Leetcode solutions to demonstrate knowledge of real world applications of MySQL.
leetcode-medium is used to store solutions for leetcode's medium level problems.
leetcode-easy is used to store solutions for leetcode's easy level problems.
MySQL-Concepts is used to store academic examples of basic SQL concepts, joins, queries, create, and aggregation.
